# د افغان طبي بوټو عکسونه

عکسونه دلته واچوئ (د `app/afghan-plants/` فولډر). د `id` شمېره ۳ رقمي کېږي:

| فایل | کارول |
|---|---|
| `001.jpg` | د بوټي اصلي عکس (په لېست او پاڼه کې) |
| `001-2.jpg`، `001-3.jpg`، `001-4.jpg` | اضافي عکسونه (اختیاري، یوازې په بوټي پاڼه کې) |

مثال: id ۴۲ ← `042.jpg`، `042-2.jpg`

- بڼه: **JPG**، پلنوالی شاوخوا ۸۰۰ پکسله، اندازه تر ۲۰۰ KB.
- که عکس نه وي، اپ هیڅ ځای خالي نه پرېږدي، یوازې متن ښیي.
- په JSON کې هیڅ بدلون ته اړتیا نشته.

## د عکس سرچینه او لایسنس (اختیاري)
په `credits.json` کې هر عکس ته یو داسې لیکنه ورزیاتولای شئ، او په بوټي پاڼه کې به ښکاره شي:

```json
{
  "42": { "author": "John Smith", "license": "CC BY-SA 4.0", "source": "commons.wikimedia.org/..." }
}
```
