# Afghan plants 101–140 (kept separate)

`afghan-plants-101-140.json` holds 40 Afghan medicinal plants (ids 101–140) that were added by mistake to
`app/ghazali_all_100_plants_final.json` and `app/app.html`. Those two files are back to the original 100 plants.

To add these 40 to the dashboard's Afghan-plants section, use the dashboard's file import
(it only adds plants that are missing and never changes existing plants or photos).
